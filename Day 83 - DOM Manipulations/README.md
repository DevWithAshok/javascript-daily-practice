# Day 83 - DOM Manipulations

## Overview

This practice focuses on understanding and performing DOM (Document Object Model) manipulations using JavaScript. It demonstrates how to access HTML elements, modify their content, update attributes, and dynamically change webpage elements.

## Features

- Access HTML elements using JavaScript
- Modify element content dynamically
- Update HTML attributes
- Change element styles
- Create and manipulate DOM elements
- Handle user interactions
- Update webpage content dynamically

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript

## Concepts Practiced

- Document Object Model (DOM)
- DOM Selection Methods
- `getElementById()`
- `querySelector()`
- `textContent`
- `innerHTML`
- `setAttribute()`
- `classList`
- Event Handling
- Dynamic Element Creation

## Learning Outcome

By completing this practice, I learned how to:

- Understand the structure of the DOM.
- Select and access HTML elements using JavaScript.
- Modify text and HTML content dynamically.
- Update element attributes and CSS classes.
- Create and manipulate HTML elements.
- Build interactive webpages using DOM manipulation.

## Use Case

DOM manipulation is essential for creating interactive web applications, updating webpage content without reloading, handling user actions, modifying UI components, and dynamically displaying data.
