# Day 12 - Button Maker

## Overview

This project is a Button Maker application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to customize a button's appearance by changing properties such as background color, font color, font size, font weight, padding, and border radius in real time.

## Features

* Customize button background color
* Change text color dynamically
* Adjust font size and font weight
* Modify padding and border radius
* Real-time preview of button styles
* Interactive and user-friendly interface

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Form Input Handling
* Dynamic CSS Styling
* JavaScript Functions
* User Interface Customization

## Learning Outcome

Learned how to capture user input, dynamically update CSS properties, manipulate DOM elements, and build an interactive customization tool using JavaScript.
