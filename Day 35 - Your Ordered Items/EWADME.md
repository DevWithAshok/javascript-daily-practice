# Day 35 - Your Ordered Items

## Overview

This project demonstrates how to create an interactive ordered items list using HTML, CSS, Bootstrap, and JavaScript. Users can select items and dynamically view or manage their ordered items through the interface.

## Features

* Display a list of items
* Select items using checkboxes
* Track selected items
* Dynamically update the ordered items
* Interactive user interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* Arrays
* Objects
* Checkboxes
* DOM Manipulation
* Event Handling
* JavaScript Functions
* Conditional Statements
* Dynamic Content Updates

## Learning Outcome

Learned how to handle user selections, work with arrays and objects, manipulate DOM elements dynamically, and build an interactive ordered-items interface using JavaScript.

## Use Case

This concept can be applied to shopping carts, food ordering systems, product selection pages, and other applications where users need to select and manage multiple items.
