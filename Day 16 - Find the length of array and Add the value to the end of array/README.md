# Day 16 - Find the Length of Array and Add the Value to the End of an Array

## Overview

This project demonstrates how to work with JavaScript arrays by finding the length of an array and adding a new value to the end using built-in array properties and methods.

## Features

* Find the total number of elements in an array
* Add a new element to the end of an array using `push()`
* Display the updated array
* Understand how arrays can grow dynamically

## Technologies Used

* JavaScript

## Concepts Practiced

* Arrays
* `length` Property
* `push()` Method
* Variables
* Console Output
* Array Manipulation

## Learning Outcome

Learned how to determine the size of an array using the `length` property, append new elements with the `push()` method, and manipulate array data efficiently using JavaScript.
