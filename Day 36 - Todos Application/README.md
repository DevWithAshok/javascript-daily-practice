# Day 36 - Todos Application

## Overview

This project is a Todos Application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to create and manage a list of tasks through an interactive interface.

## Features

* Add new todo items
* Display todo items dynamically
* Mark tasks as completed
* Delete todo items
* Manage multiple tasks
* Interactive and responsive user interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Arrays
* Objects
* Functions
* Checkboxes
* Conditional Statements
* Dynamic Element Creation
* Dynamic Content Updates

## Learning Outcome

Learned how to build a task management application using JavaScript by combining arrays, objects, functions, event handling, and DOM manipulation to dynamically create and manage todo items.

## Use Case

This project demonstrates concepts commonly used in real-world task management applications, productivity tools, and interactive web applications.
