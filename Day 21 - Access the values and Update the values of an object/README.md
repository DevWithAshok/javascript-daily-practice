# Day 21 - Access the Values and Update the Values of an Object

## Overview

This project demonstrates how to access and modify properties of a JavaScript object. It helps in understanding how objects can be used to store, retrieve, and update data dynamically using property names.

## Features

* Create a JavaScript object
* Access object properties using dot notation and bracket notation
* Update existing property values
* Display the updated object in the console
* Understand dynamic object manipulation

## Technologies Used

* JavaScript

## Concepts Practiced

* Objects
* Object Properties
* Dot Notation
* Bracket Notation
* Updating Object Values
* Console Output

## Learning Outcome

Learned how to access object properties, modify existing values, and work with JavaScript objects efficiently. This forms the foundation for handling complex data structures in real-world applications.
