# Day 13 - Tabs

## Overview

This project is a Tabs application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to switch between different tabs and view corresponding content dynamically without reloading the page.

## Features

* Multiple interactive tabs
* Dynamic content switching
* Active tab highlighting
* Smooth user experience
* Responsive and clean interface

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Class Manipulation
* Conditional Logic
* Dynamic Content Updates
* User Interface Design

## Learning Outcome

Learned how to create tab-based navigation, manage active states, update content dynamically, and build a more interactive user interface using JavaScript.
