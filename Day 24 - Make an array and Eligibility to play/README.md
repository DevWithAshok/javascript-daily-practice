# Day 24 - Make an Array and Eligibility to Play

## Overview

This project demonstrates how to create a JavaScript array, access its elements, and use conditional statements to determine a player's eligibility based on predefined criteria. It combines arrays with decision-making to solve a simple real-world problem.

## Features

* Create and initialize a JavaScript array
* Access array elements
* Check eligibility using conditional statements
* Display the eligibility result in the console
* Understand the relationship between arrays and program logic

## Technologies Used

* JavaScript

## Concepts Practiced

* Arrays
* Array Element Access
* Conditional Statements (`if`, `else`)
* Variables
* Logical Operators
* Console Output

## Learning Outcome

Learned how to create and use arrays, retrieve stored values, apply conditional logic to make decisions, and solve practical programming problems using JavaScript.
