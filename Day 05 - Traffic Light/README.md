# Day 05 - Traffic Light

## Overview

This project is a Traffic Light Simulator built using HTML, CSS, Bootstrap, and JavaScript. Users can control the traffic lights by clicking the corresponding buttons, simulating the behavior of real-world traffic signals.

## Features

* Switch between Red, Yellow, and Green lights
* Interactive button controls
* Dynamic color changes using JavaScript
* Simple and responsive user interface

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* Conditional Logic
* Dynamic CSS Updates
* User Interface Interaction

## Learning Outcome

Learned how to manipulate DOM elements dynamically, handle user events, update styles based on actions, and build an interactive web application using JavaScript.
