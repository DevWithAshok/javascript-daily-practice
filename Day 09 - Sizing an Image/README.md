# Day 09 - Sizing an Image

## Overview

This project is an Image Resizer application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to increase or decrease the size of an image dynamically through interactive controls.

## Features

* Increase image size
* Decrease image size
* Display current image dimensions
* Dynamic updates without page reload
* Simple and responsive user interface

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Element Property Modification
* Functions
* Variables
* Dynamic UI Updates

## Learning Outcome

Learned how to manipulate element dimensions using JavaScript, respond to user interactions, update content dynamically, and build an interactive image resizing application.
