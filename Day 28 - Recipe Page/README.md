# Day 28 - Recipe Page

## Overview

This project is a simple Recipe Page built using HTML, CSS, Bootstrap, and JavaScript. It demonstrates how to create a structured web page for displaying recipe information in a clear and user-friendly format.

## Features

* Display recipe information
* Show ingredients and preparation details
* Structured and readable layout
* Responsive design using Bootstrap
* Interactive elements using JavaScript

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* HTML Structure
* CSS Styling
* Bootstrap Layout
* JavaScript
* DOM Manipulation
* User Interaction
* Responsive Web Design

## Learning Outcome

Learned how to structure and style a recipe-based web page, use Bootstrap for responsive layouts, and apply JavaScript concepts to add interactivity to a webpage.
