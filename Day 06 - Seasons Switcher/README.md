# Day 06 - Seasons Switcher

## Overview

This project is a Seasons Switcher application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to switch between different seasons, updating the displayed image and background dynamically based on the selected season.

## Features

* Switch between Spring, Summer, Autumn, and Winter
* Dynamically update images and background
* Interactive button-based navigation
* Clean and responsive user interface

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* Element Selection
* Dynamic Image and Style Updates
* User Interaction

## Learning Outcome

Learned how to use JavaScript to dynamically update images, modify styles, respond to user events, and build an interactive application with a responsive interface.
