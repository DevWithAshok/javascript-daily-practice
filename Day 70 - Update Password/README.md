# Day 70 - Update Password

## Overview

This project is an Update Password form built using HTML, CSS, Bootstrap, and JavaScript. It focuses on collecting a new password, confirming the password, and validating the inputs before allowing the user to proceed.

## Features

* Enter a new password
* Confirm the new password
* Validate password inputs
* Check whether both passwords match
* Display validation error messages
* Provide an interactive form interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* HTML Forms
* Form Submission
* DOM Manipulation
* Event Handling
* Input Validation
* Conditional Statements
* String Comparison
* Error Message Handling
* Dynamic Content Updates

## Learning Outcome

By completing this practice, I learned how to:

* Capture values from HTML input fields.
* Validate user input using JavaScript.
* Compare new and confirmed passwords.
* Display error messages when validation fails.
* Handle form submission events.
* Improve user experience through form validation.

## Use Case

An update password form can be used in web applications that allow users to change their account passwords while ensuring that the entered passwords match.
