# Day 31 - Checkbox with Label

## Overview

This project demonstrates how to create and work with checkboxes and labels using HTML, CSS, Bootstrap, and JavaScript. It focuses on handling user selections and dynamically responding to checkbox interactions.

## Features

* Create checkbox elements
* Add labels for checkbox options
* Select and deselect options
* Handle checkbox interactions using JavaScript
* Update the interface based on user selection

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* HTML Checkboxes
* Labels
* DOM Manipulation
* Event Handling
* JavaScript Functions
* Conditional Statements
* Dynamic Content Updates

## Learning Outcome

Learned how to create and manage checkbox elements, associate labels with form controls, detect user selections, and use JavaScript to dynamically respond to checkbox interactions.
