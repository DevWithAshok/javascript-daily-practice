# Day 26 - Eligibility to Vote and Car Brand Names

## Overview

This project demonstrates how to use conditional statements to determine voting eligibility and how to work with arrays by storing and displaying car brand names. It combines decision-making with array operations to strengthen JavaScript fundamentals.

## Features

* Check voting eligibility based on age
* Use conditional statements (`if`, `else`)
* Create an array of car brand names
* Access and display array elements
* Display results using `console.log()`

## Technologies Used

* JavaScript

## Concepts Practiced

* Conditional Statements (`if`, `else`)
* Arrays
* Variables
* Comparison Operators
* Array Element Access
* Console Output

## Learning Outcome

Learned how to implement conditional logic to solve real-world problems, create and manipulate arrays, and display information effectively using JavaScript.
