# Day 82 - HTML Checkbox Input Element

## Overview

This practice focuses on using HTML checkbox input elements and handling checkbox interactions with JavaScript. It demonstrates how to capture user selections and dynamically respond to changes in checkbox states.

## Features

- Create checkbox input elements
- Allow users to select and deselect options
- Capture checkbox states
- Handle checkbox change events
- Update webpage content based on selections
- Create interactive form elements

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript

## Concepts Practiced

- HTML Checkbox Input
- DOM Manipulation
- Event Handling
- `checked` Property
- `change` Event
- User Input Processing
- Conditional Statements
- Functions
- Dynamic Content Updates

## Learning Outcome

By completing this practice, I learned how to:

- Create checkbox elements using HTML.
- Access checkbox elements using JavaScript.
- Check whether a checkbox is selected using the `checked` property.
- Handle checkbox interactions using the `change` event.
- Update webpage content based on user selections.
- Build interactive forms using JavaScript.

## Use Case

Checkboxes are commonly used in registration forms, surveys, settings pages, task management applications, and preference selection interfaces where users can select multiple options.
