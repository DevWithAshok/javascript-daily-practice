# Day 14 - Arrays Basics

## Overview

This project demonstrates the basics of arrays in JavaScript. It shows how to create an array containing multiple values of different data types and display the array using `console.log()`.

## Features

* Create a JavaScript array
* Store multiple values in a single variable
* Use different data types in the same array
* Display array contents in the console

## Technologies Used

* JavaScript

## Concepts Practiced

* Arrays
* Variables
* Mixed Data Types
* Console Output
* Data Storage

## Learning Outcome

Learned how to create and use arrays in JavaScript, store multiple values efficiently, and work with different data types such as strings, numbers, and booleans within a single array.
