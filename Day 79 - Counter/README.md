# Day 79 - Counter

## Overview

This project is an interactive Counter application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to increase, decrease, and reset a counter value through button interactions.

## Features

- Increase the counter value
- Decrease the counter value
- Reset the counter to its initial value
- Display the current count dynamically
- Handle button click events
- Interactive and user-friendly interface

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript

## Concepts Practiced

- DOM Manipulation
- Event Handling
- Functions
- Variables
- Conditional Statements
- Number Operations
- Dynamic Content Updates

## Learning Outcome

By completing this practice, I learned how to:

- Access and update HTML elements using JavaScript.
- Handle button click events.
- Perform increment and decrement operations.
- Reset counter values dynamically.
- Update webpage content based on user interactions.

## Use Case

A counter application can be used for tracking quantities, scores, clicks, votes, and other numerical values in interactive web applications.
