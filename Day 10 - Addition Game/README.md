# Day 10 - Addition Game

## Overview

This project is an Addition Game built using HTML, CSS, Bootstrap, and JavaScript. Users are presented with two numbers and must enter the correct sum. The application validates the answer and provides instant feedback.

## Features

* Generates addition-based questions
* Accepts user input for answers
* Validates the entered answer
* Displays success or error messages
* Interactive and beginner-friendly interface

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* User Input Handling
* Conditional Statements
* Arithmetic Operations
* Dynamic Content Updates

## Learning Outcome

Learned how to capture and validate user input, compare values, display feedback dynamically, and create an interactive educational game using JavaScript.
