# Day 51 - Todo Application

## Overview

This project is a Todo Application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to create and manage a list of tasks through an interactive interface.

## Features

* Add new todo items
* Display todo items dynamically
* Mark tasks as completed
* Remove todo items
* Use checkboxes to manage task status
* Interactive and user-friendly interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* Arrays
* Objects
* Conditional Statements
* Dynamic HTML Elements
* Checkbox Handling
* JavaScript Variables

## Learning Outcome

By completing this practice, I learned how to:

* Create and manage todo items dynamically.
* Manipulate HTML elements using JavaScript.
* Handle user interactions and events.
* Use arrays and objects to manage task data.
* Update the UI based on user actions.

## Use Case

A Todo Application can be used to organize daily tasks, track completed activities, and manage simple task lists.
