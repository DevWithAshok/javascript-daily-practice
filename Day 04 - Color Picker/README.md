# Day 04 - Color Picker

## Overview

This project is a simple Color Picker application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to change the background color of a container by clicking different color buttons.

## Features

* Change background color dynamically
* Display the selected color code
* Interactive user interface
* Instant visual feedback on button clicks

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* Element Selection
* Dynamic Style Updates
* User Interaction

## Learning Outcome

Learned how to use JavaScript to modify CSS properties dynamically, respond to user actions through events, and create an interactive color selection interface.
