# Day 27 - User Profile

## Overview

This project demonstrates how to create and work with a user profile using JavaScript. It focuses on storing user-related information and displaying or manipulating the profile data using JavaScript objects and DOM concepts.

## Features

* Create a user profile
* Store user information using JavaScript
* Access and display profile details
* Update profile information dynamically
* Practice working with structured user data

## Technologies Used

* HTML
* CSS
* JavaScript
* Bootstrap

## Concepts Practiced

* JavaScript Objects
* Object Properties
* DOM Manipulation
* Event Handling
* Variables
* Functions
* Dynamic Content Updates

## Learning Outcome

Learned how to represent user information using JavaScript objects, access object properties, and dynamically work with profile data to create an interactive user profile application.
