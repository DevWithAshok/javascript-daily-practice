# Day 25 - Sum of the Values of an Array and Log the Values from Each Object

## Overview

This project demonstrates how to calculate the sum of values in a JavaScript array and access properties from multiple objects. It helps in understanding array traversal, object handling, and combining these concepts to process structured data.

## Features

* Create and work with JavaScript arrays
* Calculate the sum of array elements
* Store multiple objects in an array
* Access and log values from each object
* Display results using `console.log()`

## Technologies Used

* JavaScript

## Concepts Practiced

* Arrays
* Objects
* Array Traversal
* Object Property Access
* Arithmetic Operations
* Variables
* Console Output

## Learning Outcome

Learned how to iterate through arrays, calculate the sum of numeric values, access properties of objects, and work with collections of objects to process and display data effectively.
