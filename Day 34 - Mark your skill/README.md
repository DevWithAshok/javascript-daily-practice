# Day 34 - Mark Your Skill

## Overview

This project demonstrates how to create an interactive skill selection interface using HTML, CSS, Bootstrap, and JavaScript. Users can select their skills using checkboxes and dynamically mark the selected skills.

## Features

* Display multiple skills
* Select skills using checkboxes
* Mark selected skills dynamically
* Handle user interactions
* Update the interface based on selected skills

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* Checkboxes
* DOM Manipulation
* Event Handling
* JavaScript Functions
* Conditional Statements
* CSS Class Manipulation
* Dynamic UI Updates

## Learning Outcome

Learned how to handle multiple checkbox selections, access related HTML elements through the DOM, dynamically apply styles, and create an interactive skill-selection interface using JavaScript.

## Use Case

This concept can be used in real-world applications such as skill selection forms, registration pages, profile builders, and job application forms.
