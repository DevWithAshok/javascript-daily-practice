# Day 43 - Index of First Occurrence

## Overview

This project demonstrates how to find the index of the first occurrence of a specific value in a JavaScript array using the `indexOf()` method.

## Features

* Create and work with JavaScript arrays
* Search for a specific value
* Find the index of its first occurrence
* Handle values that are not present in the array
* Display the result using `console.log()`

## Technologies Used

* JavaScript

## Concepts Practiced

* Arrays
* `indexOf()` Method
* Array Searching
* Index Positions
* Variables
* Console Output
* Conditional Statements

## Learning Outcome

Learned how to use the `indexOf()` method to find the position of the first occurrence of an element in an array. Also learned how JavaScript returns `-1` when the specified value is not found.

## Use Case

The `indexOf()` method is useful for searching arrays, checking the position of values, validating data, and working with lists of items in JavaScript applications.
