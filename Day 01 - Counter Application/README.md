# Day 01 - Counter Application

## Overview

This project is a simple Counter Application built using HTML, CSS, Bootstrap, and JavaScript.

## Features

* Increase the counter value
* Decrease the counter value
* Reset the counter to zero
* Counter text changes color based on the value:

  * Green for positive values
  * Red for negative values
  * Black for zero

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* Conditional Statements
* Variables
* JavaScript Number Operations

## Learning Outcome

Learned how to access HTML elements using JavaScript, update content dynamically, handle button click events, and apply styles based on conditions.
