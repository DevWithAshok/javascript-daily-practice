# Day 11 - Random Color Generator

## Overview

This project is a Random Color Generator built using HTML, CSS, Bootstrap, and JavaScript. It generates a random color each time the user clicks a button and updates the background color dynamically while displaying the corresponding color code.

## Features

* Generate random colors instantly
* Change background color dynamically
* Display the generated color code
* Interactive and responsive user interface
* One-click color generation

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* JavaScript Math Functions
* Random Number Generation
* String Manipulation
* Dynamic Style Updates

## Learning Outcome

Learned how to generate random values using JavaScript, dynamically update CSS properties, manipulate strings, and create an interactive application that responds to user actions in real time.
