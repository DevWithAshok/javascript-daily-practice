# Day 54 - Clear The Counter

## Overview

This project is a simple Counter Application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to increase, decrease, and clear the counter value through button interactions.

## Features

* Increase the counter value
* Decrease the counter value
* Clear or reset the counter
* Display the current counter value dynamically
* Interactive buttons
* Simple and responsive user interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* Variables
* Conditional Statements
* Number Operations
* Dynamic Content Update

## Learning Outcome

By completing this practice, I learned how to:

* Access and update HTML elements using JavaScript.
* Handle button click events.
* Perform increment and decrement operations.
* Reset a value using JavaScript.
* Dynamically update content on a webpage.

## Use Case

A counter can be used in applications for tracking quantities, scores, clicks, items, votes, or other numerical values.
