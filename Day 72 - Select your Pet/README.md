# Day 72 - Select Your Pet

## Overview

This project is a Select Your Pet application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to select a pet through an interactive interface and understand how to handle selection inputs using JavaScript.

## Features

* Display pet selection options
* Allow users to select a pet
* Capture the selected option
* Handle user interactions
* Update webpage content dynamically
* Provide a simple and user-friendly interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* HTML Forms
* Radio Buttons / Selection Inputs
* DOM Manipulation
* Event Handling
* User Input Processing
* Conditional Statements
* Functions
* Dynamic Content Updates

## Learning Outcome

By completing this practice, I learned how to:

* Create selection options using HTML.
* Capture selected values using JavaScript.
* Handle user selection events.
* Access and update DOM elements dynamically.
* Use conditional statements to process user choices.
* Build interactive forms and selection-based interfaces.

## Use Case

A pet selection interface can be used in pet adoption websites, registration forms, surveys, and applications where users need to choose from multiple options.
