# Day 20 - Create & Log an Object

## Overview

This project demonstrates the basics of JavaScript objects by creating an object with multiple properties and displaying it in the console. It introduces how objects are used to store related data as key-value pairs.

## Features

* Create a JavaScript object
* Store data using key-value pairs
* Access object properties
* Display the object using `console.log()`
* Understand object structure and syntax

## Technologies Used

* JavaScript

## Concepts Practiced

* Objects
* Key-Value Pairs
* Variables
* Object Properties
* Console Output
* Data Organization

## Learning Outcome

Learned how to create and work with JavaScript objects, organize related data using key-value pairs, access object properties, and display object information using `console.log()`.
