# Day 77 - Speed Typing Test

## Overview

This project is a Speed Typing Test application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to test their typing speed by typing a given paragraph within a limited time.

## Features

- Display a paragraph for typing practice
- Allow users to type the given text
- Start a countdown timer
- Calculate typing speed
- Track typing accuracy
- Display test results
- Provide an interactive typing interface

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript

## Concepts Practiced

- DOM Manipulation
- Event Handling
- Keyboard Events
- User Input Processing
- String Handling
- Timer Functions
- `setInterval()`
- Conditional Statements
- Functions
- Dynamic Content Updates

## Learning Outcome

By completing this practice, I learned how to:

- Capture and process keyboard input.
- Implement countdown timers using JavaScript.
- Compare typed text with the given paragraph.
- Calculate typing speed and accuracy.
- Handle keyboard events and user interactions.
- Update test results dynamically using DOM manipulation.

## Use Case

A Speed Typing Test can be used to improve typing speed, measure typing accuracy, practice keyboard skills, and evaluate typing performance.
