# Day 71 - Add User

## Overview

This project is an Add User application built using HTML, CSS, Bootstrap, and JavaScript. It focuses on collecting user information through a form, validating the input, and displaying user details dynamically on the webpage.

## Features

* Enter user information through a form
* Validate user input
* Add new user details
* Display user information dynamically
* Handle form submission
* Provide a user-friendly interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* HTML Forms
* DOM Manipulation
* Event Handling
* User Input Processing
* Form Validation
* Functions
* Conditional Statements
* Arrays and Objects
* Dynamic HTML Elements

## Learning Outcome

By completing this practice, I learned how to:

* Capture user details from HTML input fields.
* Handle form submissions using JavaScript.
* Validate user input before processing it.
* Add and display user information dynamically.
* Manipulate webpage elements using the DOM.
* Create interactive forms using HTML, CSS, Bootstrap, and JavaScript.

## Use Case

An Add User application can be used in registration forms, contact management systems, employee directories, and other applications that collect and display user information.

Completed **71 days of JavaScript practice**, strengthening my understanding of form handling, input validation, DOM manipulation, and dynamic data display.
