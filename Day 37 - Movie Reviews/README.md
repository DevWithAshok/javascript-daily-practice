# Day 37 - Movie Reviews

## Overview

This project is a Movie Reviews application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to view and manage movie review information through a structured and interactive interface.

## Features

* Display movie details
* Add and display movie reviews
* Organize review information
* Dynamically update content
* Interactive and responsive user interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* JavaScript Objects
* Arrays
* DOM Manipulation
* Event Handling
* Functions
* User Input Handling
* Dynamic Element Creation
* Dynamic Content Updates

## Learning Outcome

Learned how to represent movie and review information using JavaScript objects and arrays, dynamically create and update DOM elements, handle user input, and build an interactive movie review interface.

## Use Case

This project demonstrates concepts that can be applied to movie review platforms, rating systems, feedback forms, and other data-driven web applications.
