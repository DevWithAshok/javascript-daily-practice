# Day 33 - Toggle the Strike Through

## Overview

This project demonstrates how to toggle a strike-through effect on text using HTML, CSS, and JavaScript. It allows users to mark text as completed or incomplete by dynamically applying and removing the strike-through style.

## Features

* Add a strike-through effect to text
* Remove the strike-through effect
* Toggle the text style through user interaction
* Dynamically update the appearance of elements

## Technologies Used

* HTML
* CSS
* JavaScript
* Bootstrap

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* CSS Class Manipulation
* Conditional Logic
* Dynamic Style Updates

## Learning Outcome

Learned how to use JavaScript to dynamically add and remove CSS classes, respond to user interactions, and change the visual state of HTML elements.

## Use Case

The same concept is commonly used in todo applications to visually indicate that a task has been completed.
