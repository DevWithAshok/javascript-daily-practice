# Day 55 - Custom Range Counter

## Overview

This project is a Custom Range Counter built using HTML, CSS, Bootstrap, and JavaScript. It allows users to control a counter within a custom range by providing minimum and maximum values.

## Features

* Set a custom minimum value
* Set a custom maximum value
* Increase the counter value
* Decrease the counter value
* Display the current counter value dynamically
* Manage counter values within a defined range
* Interactive and responsive user interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* User Input
* Variables
* Conditional Statements
* Number Operations
* Dynamic Content Update
* Range Validation

## Learning Outcome

By completing this practice, I learned how to:

* Get custom range values from user input.
* Update a counter dynamically using JavaScript.
* Apply conditions to control the counter range.
* Handle user interactions through button events.
* Manipulate webpage content using the DOM.

## Use Case

A custom range counter can be used for quantity selection, score tracking, pagination controls, product quantity selection, and other applications where values need to stay within a specific range.
