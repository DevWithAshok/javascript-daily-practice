# Day 57 - Theme Switcher

## Overview

This project is a Theme Switcher built using HTML, CSS, Bootstrap, and JavaScript. It allows users to switch between different themes dynamically through an interactive interface.

## Features

* Switch between available themes
* Change the webpage appearance dynamically
* Interactive theme selection
* Update styles using JavaScript
* Simple and user-friendly interface
* Responsive design using Bootstrap

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* Variables
* Conditional Statements
* CSS Styling
* Dynamic Style Updates
* User Interaction

## Learning Outcome

By completing this practice, I learned how to:

* Handle theme selection using JavaScript.
* Dynamically change webpage styles.
* Manipulate CSS properties through the DOM.
* Respond to user interactions using event handlers.
* Build an interactive and customizable user interface.

## Use Case

A theme switcher can be used to provide users with different visual modes, such as light and dark themes, and improve the customization and usability of web applications.
