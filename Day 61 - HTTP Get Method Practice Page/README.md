# Day 61 - HTTP GET Method Practice Page

## Overview

This project is an HTTP GET Method Practice Page built using HTML, CSS, Bootstrap, and JavaScript. It focuses on understanding how to send GET requests and work with data retrieved from a server.

## Features

* Practice sending HTTP GET requests
* Retrieve data from an API
* Handle server responses
* Display retrieved data dynamically
* Use JavaScript for API interaction
* Simple and responsive user interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* HTTP GET Method
* API Requests
* JavaScript Fetch API
* Promises
* Asynchronous JavaScript
* DOM Manipulation
* Event Handling
* JSON Data
* Dynamic Content Rendering

## Learning Outcome

By completing this practice, I learned how to:

* Understand the purpose of the HTTP GET method.
* Send GET requests using JavaScript.
* Work with API responses.
* Process JSON data returned from an API.
* Display fetched data dynamically on a webpage.
* Understand the basics of asynchronous API communication.

## Use Case

HTTP GET requests are commonly used to retrieve information from servers, such as user details, product data, posts, weather information, and other API-based resources.

Completed **61 days of JavaScript practice**, strengthening my understanding of API requests, the HTTP GET method, asynchronous JavaScript, JSON data, and dynamic content rendering.
