# Day 52 - Chatbot

## Overview

This project is a simple interactive Chatbot built using HTML, CSS, Bootstrap, and JavaScript. It allows users to enter messages and interact with the chatbot through a dynamic user interface.

## Features

* Enter and send messages
* Display user messages dynamically
* Generate chatbot responses
* Interactive chat interface
* Dynamic message rendering
* Responsive user interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* User Input
* Conditional Statements
* Dynamic HTML Elements
* String Handling
* JavaScript Variables

## Learning Outcome

By completing this practice, I learned how to:

* Capture and process user input.
* Handle button and user interaction events.
* Dynamically create and display chat messages.
* Use JavaScript logic to generate responses.
* Build an interactive web interface using DOM manipulation.

## Use Case

A chatbot interface can be used for basic customer support, FAQs, automated responses, and interactive web applications.
