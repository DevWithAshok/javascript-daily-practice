# Day 40 - Greeting Card

## Overview

This project is a Greeting Card application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to create and display a personalized greeting message through an interactive web interface.

## Features

* Display a greeting card
* Create personalized greeting content
* Dynamically update the card
* Interactive user interface
* Responsive design using Bootstrap

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* JavaScript Functions
* User Input Handling
* Dynamic Content Updates
* CSS Styling
* Responsive Web Design

## Learning Outcome

Learned how to create an interactive greeting card using JavaScript, handle user input, dynamically update HTML content, and combine JavaScript with HTML and CSS to build a complete web application.

## Use Case

This concept can be applied to personalized greeting cards, invitation pages, celebration messages, feedback forms, and other interactive web interfaces.
