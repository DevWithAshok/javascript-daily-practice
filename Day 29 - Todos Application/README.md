# Day 29 - Todos Application

## Overview

This project is a Todos Application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to manage a list of tasks by adding, completing, and deleting todos through an interactive interface.

## Features

* Add new todo items
* Mark todos as completed
* Delete todo items
* Display todos dynamically
* Interactive and user-friendly interface
* Responsive design using Bootstrap

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* JavaScript Functions
* Arrays
* Objects
* Conditional Statements
* Dynamic Element Creation
* User Input Handling
* Dynamic Content Updates

## Learning Outcome

Learned how to build an interactive task management application using JavaScript. Practiced creating and manipulating DOM elements dynamically, handling user events, managing todo data, and updating the user interface based on user actions.
