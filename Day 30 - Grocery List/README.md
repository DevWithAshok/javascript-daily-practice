# Day 30 - Grocery List

## Overview

The Grocery List is a simple web application developed using HTML, CSS, and JavaScript. The application allows users to add grocery items to a list and interact with the items dynamically.

This project was created as part of my JavaScript Daily Practice series to strengthen my understanding of DOM manipulation, event handling, and dynamic webpage updates.

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Features

* Add new grocery items
* Display added items in the grocery list
* Dynamically create and update list elements
* Handle user interactions using JavaScript
* Simple and clean user interface
* Organized HTML, CSS, and JavaScript structure

## How It Works

1. The user enters the name of a grocery item.
2. JavaScript captures the entered value.
3. A new list item is created dynamically.
4. The grocery item is displayed on the webpage.
5. Users can interact with the generated list items.

## JavaScript Concepts Practiced

* DOM Manipulation
* Event Handling
* Event Listeners
* Functions
* Variables
* Conditional Statements
* Creating HTML elements dynamically
* Adding elements to the DOM
* Accessing and modifying element properties
* Handling user input

## Files

### `grocery.html`

Contains the basic structure of the Grocery List application, including the input field, buttons, and list container.

### `grocery.css`

Contains the styling of the application, including layout, spacing, fonts, colors, and overall appearance.

### `grocery.js`

Contains the JavaScript logic used to handle user input, create grocery items, and dynamically update the list.

## What I Learned

Through this project, I practiced how JavaScript can be used to make a webpage interactive instead of keeping it as a static page.

I learned how to:

* Capture values entered by the user
* Respond to user actions
* Select HTML elements using JavaScript
* Create new elements dynamically
* Modify the content of webpage elements
* Add dynamically created elements to the webpage
* Connect HTML, CSS, and JavaScript to build an interactive application

## Key Learning

The main focus of this project was understanding how **JavaScript interacts with the DOM**. By manipulating DOM elements, a webpage can respond to user actions and update its content without manually changing the HTML code.
