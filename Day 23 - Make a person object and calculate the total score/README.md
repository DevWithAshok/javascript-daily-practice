# Day 23 - Make a Person Object and Calculate the Total Score

## Overview

This project demonstrates how to create a JavaScript object representing a person and calculate the total score using the object's properties. It helps in understanding how objects can store related information and how their values can be used in calculations.

## Features

* Create a person object with multiple properties
* Store subject scores as object properties
* Access object values
* Calculate the total score using object data
* Display the calculated result in the console

## Technologies Used

* JavaScript

## Concepts Practiced

* Objects
* Object Properties
* Dot Notation
* Variables
* Arithmetic Operations
* Console Output

## Learning Outcome

Learned how to create and use JavaScript objects to represent real-world data, access object properties, perform calculations using stored values, and display the results efficiently.
