# Day 66 - Wikipedia Search Application

## Overview

This project is a Wikipedia Search Application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to search for topics and view relevant information retrieved from the Wikipedia search API.

## Features

* Search for topics and keywords
* Fetch search results from the Wikipedia API
* Display relevant search results dynamically
* Show titles and descriptions of search results
* Provide links to relevant Wikipedia articles
* Update results based on user input
* User-friendly and responsive interface

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript
* Wikipedia API

## Concepts Practiced

* API Integration
* HTTP GET Requests
* JavaScript Fetch API
* Asynchronous JavaScript
* Promises
* JSON Data Handling
* DOM Manipulation
* Event Handling
* User Input Processing
* Dynamic Content Rendering

## Learning Outcome

By completing this practice, I learned how to:

* Capture and process search queries from users.
* Fetch information from an external API.
* Handle asynchronous API requests using JavaScript.
* Process JSON responses and extract relevant information.
* Display search results dynamically on a webpage.
* Create links to external resources based on API results.

## Use Case

A Wikipedia Search Application can help users quickly find information about topics such as science, technology, history, geography, and other subjects without manually navigating through the Wikipedia website.
