# Day 08 - Tip Calculator

## Overview

This project is a Tip Calculator built using HTML, CSS, Bootstrap, and JavaScript. It helps users calculate the tip amount and total bill based on the entered bill amount and tip percentage.

## Features

* Enter bill amount
* Calculate tip amount based on percentage
* Display total amount including tip
* User-friendly and interactive interface
* Instant calculation using JavaScript

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* User Input Handling
* Functions
* Arithmetic Operations
* Dynamic Content Updates

## Learning Outcome

Learned how to capture user input, perform calculations using JavaScript, update web page content dynamically, and build a practical utility application.
