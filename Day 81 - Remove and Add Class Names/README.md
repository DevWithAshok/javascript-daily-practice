# Day 81 - Remove and Add Class Names

## Overview

This practice focuses on dynamically adding and removing CSS class names from HTML elements using JavaScript. It demonstrates how to modify the appearance and styling of webpage elements through DOM manipulation.

## Features

- Add CSS class names dynamically
- Remove existing class names
- Modify element styles using JavaScript
- Handle button click events
- Update webpage appearance dynamically
- Create interactive UI elements

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript

## Concepts Practiced

- DOM Manipulation
- `classList.add()`
- `classList.remove()`
- CSS Classes
- Event Handling
- Functions
- Dynamic Styling
- JavaScript Variables

## Learning Outcome

By completing this practice, I learned how to:

- Access HTML elements using JavaScript.
- Add CSS classes dynamically using `classList.add()`.
- Remove CSS classes using `classList.remove()`.
- Change webpage styling through JavaScript.
- Handle user interactions using event listeners.
- Manipulate element classes dynamically.

## Use Case

Adding and removing class names is useful for implementing theme switching, active navigation menus, highlighting selected elements, showing and hiding content, and creating interactive user interfaces.
