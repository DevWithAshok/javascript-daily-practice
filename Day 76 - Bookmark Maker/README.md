# Day 76 - Bookmark Maker

## Overview

This project is a Bookmark Maker application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to add and manage website bookmarks by providing a website name and URL through an interactive form.

## Features

- Add website bookmarks
- Enter website names and URLs
- Validate user inputs
- Display saved bookmarks dynamically
- Provide clickable links to bookmarked websites
- Handle form submissions
- User-friendly and responsive interface

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript

## Concepts Practiced

- DOM Manipulation
- Event Handling
- HTML Forms
- User Input Processing
- Form Validation
- Arrays and Objects
- Conditional Statements
- Dynamic HTML Elements
- URL Handling

## Learning Outcome

By completing this practice, I learned how to:

- Collect website details through HTML forms.
- Validate website names and URLs.
- Create and display bookmark elements dynamically.
- Handle form submission using JavaScript.
- Work with arrays and objects to manage bookmark data.
- Create clickable links using DOM manipulation.

## Use Case

A Bookmark Maker can help users organize and quickly access frequently visited websites. It is useful for personal link management, resource collections, and productivity applications.
