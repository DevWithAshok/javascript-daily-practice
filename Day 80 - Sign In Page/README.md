# Day 80 - Sign In Page

## Overview

This project is a Sign In Page built using HTML, CSS, Bootstrap, and JavaScript. It provides a user-friendly interface for entering login credentials and practicing form handling and input validation.

## Features

- Enter username or email
- Enter password
- Handle form submission
- Validate user input
- Display appropriate validation messages
- Interactive sign-in interface
- Responsive design using Bootstrap

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript

## Concepts Practiced

- HTML Forms
- Input Fields
- Form Validation
- DOM Manipulation
- Event Handling
- User Input Processing
- Conditional Statements
- Functions
- Dynamic Error Messages

## Learning Outcome

By completing this practice, I learned how to:

- Create a sign-in form using HTML.
- Capture username and password values.
- Validate form inputs using JavaScript.
- Handle form submission events.
- Display validation messages dynamically.
- Build interactive user interfaces using DOM manipulation.

## Use Case

A sign-in page is commonly used in websites and applications to allow registered users to access their accounts through authentication interfaces.

Completed **80 days of JavaScript practice**, strengthening my understanding of form handling, input validation, event handling, and DOM manipulation.
