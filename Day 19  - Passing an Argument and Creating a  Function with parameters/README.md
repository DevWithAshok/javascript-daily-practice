# Day 18 - Create and Return a Value in Function

## Overview

This project demonstrates how to create JavaScript functions that return values using the `return` statement. It helps in understanding how functions process data, produce results, and make code more reusable and organized.

## Features

* Create reusable JavaScript functions
* Return values using the `return` statement
* Store returned values in variables
* Display function results using `console.log()`

## Technologies Used

* JavaScript

## Concepts Practiced

* Functions
* `return` Statement
* Variables
* Function Calls
* Console Output
* Code Reusability

## Learning Outcome

Learned how to define functions that return values, use the returned results in other parts of a program, and write modular, reusable JavaScript code using the `return` statement.
