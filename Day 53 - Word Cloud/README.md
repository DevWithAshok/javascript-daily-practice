# Day 53 - Word Cloud

## Overview

This project is a simple interactive Word Cloud application built using HTML, CSS, Bootstrap, and JavaScript. It allows users to enter words and dynamically displays them as a word cloud.

## Features

* Enter words through user input
* Generate words dynamically
* Display words in the word cloud
* Create multiple word elements
* Interactive user interface
* Responsive design using Bootstrap

## Technologies Used

* HTML
* CSS
* Bootstrap
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* User Input
* Dynamic HTML Elements
* Arrays
* Loops
* JavaScript Variables
* CSS Styling

## Learning Outcome

By completing this practice, I learned how to:

* Capture and process user input using JavaScript.
* Create HTML elements dynamically.
* Display multiple values on a webpage.
* Use loops and arrays to process data.
* Combine JavaScript with CSS to create dynamic visual content.

## Use Case

A Word Cloud can be used to visually represent frequently used words in text, survey responses, feedback, articles, and other collections of text data.
