# Day 84 - Hourly Stop Watch

## Overview

This project is an Hourly Stopwatch application built using HTML, CSS, Bootstrap, and JavaScript. It focuses on implementing a stopwatch functionality to track elapsed time and display time updates dynamically.

## Features

- Start the stopwatch
- Track elapsed time
- Display hours, minutes, and seconds
- Update the timer dynamically
- Stop or pause the stopwatch
- Reset the stopwatch
- Interactive and user-friendly interface

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript

## Concepts Practiced

- DOM Manipulation
- Event Handling
- JavaScript Timers
- `setInterval()`
- `clearInterval()`
- `Date` Object
- Functions
- Variables
- Conditional Statements
- Dynamic Content Updates

## Learning Outcome

By completing this practice, I learned how to:

- Implement stopwatch functionality using JavaScript.
- Work with JavaScript timer functions.
- Track and calculate elapsed time.
- Display time in hours, minutes, and seconds.
- Start, stop, and reset timer operations.
- Update webpage content dynamically using DOM manipulation.

## Use Case

A stopwatch can be used in sports activities, productivity applications, time-tracking systems, experiments, and other applications that require measuring elapsed time.
