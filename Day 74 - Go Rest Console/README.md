# Day 74 - Go Rest Console

## Overview

This practice focuses on working with the GoREST API using JavaScript. It helps understand how to interact with REST APIs, send HTTP requests, retrieve data, and handle server responses.

## Features

- Practice REST API communication
- Interact with API endpoints
- Send HTTP requests
- Retrieve and process API data
- Handle server responses
- Work with JSON data
- Display API results

## Technologies Used

- HTML
- CSS
- Bootstrap
- JavaScript
- GoREST API

## Concepts Practiced

- REST API
- HTTP Methods
- HTTP GET Requests
- HTTP POST Requests
- HTTP PUT Requests
- HTTP DELETE Requests
- Fetch API
- JSON Data Handling
- Asynchronous JavaScript
- Promises
- API Response Handling

## Learning Outcome

By completing this practice, I learned how to:

- Understand REST API communication.
- Interact with external API endpoints.
- Send HTTP requests using JavaScript.
- Process JSON data received from APIs.
- Handle asynchronous API operations.
- Understand how different HTTP methods are used to manage server resources.

## Use Case

REST APIs are commonly used in web applications to retrieve, create, update, and delete data. They help frontend applications communicate with backend services.
