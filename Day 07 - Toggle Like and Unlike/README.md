# Day 07 - Toggle Like and Unlike

## Overview

This project is a Like and Unlike Toggle application built using HTML, CSS, Bootstrap, and JavaScript. Users can click the Like button to toggle between liked and unliked states, with visual changes reflecting the current status.

## Features

* Toggle between Like and Unlike states
* Dynamic icon and button style updates
* Instant visual feedback on user interaction
* Simple and interactive user interface

## Technologies Used

* HTML
* CSS
* Bootstrap 4
* JavaScript

## Concepts Practiced

* DOM Manipulation
* Event Handling
* Functions
* Conditional Statements
* Class Manipulation
* Dynamic UI Updates

## Learning Outcome

Learned how to handle user interactions, toggle element states, dynamically update classes and styles, and create an engaging user experience using JavaScript.
