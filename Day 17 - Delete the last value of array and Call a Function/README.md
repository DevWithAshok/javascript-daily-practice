# Day 17 - Delete the Last Value of an Array and Call a Function

## Overview

This project demonstrates how to remove the last element from a JavaScript array using the `pop()` method and how to organize code using functions. It helps build a strong understanding of array manipulation and function invocation.

## Features

* Remove the last element from an array using `pop()`
* Call a JavaScript function to perform operations
* Display the updated array
* Understand how array data changes dynamically

## Technologies Used

* JavaScript

## Concepts Practiced

* Arrays
* `pop()` Method
* Functions
* Function Calls
* Variables
* Console Output
* Array Manipulation

## Learning Outcome

Learned how to remove the last element from an array using the `pop()` method, create reusable functions, invoke functions to execute specific tasks, and manipulate array data efficiently using JavaScript.
